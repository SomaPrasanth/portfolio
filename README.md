# Soma Prasanth R — Portfolio

Personal portfolio site, live at **https://somaprasanthr.vercel.app**.

Built with React and Vite, styled with plain CSS (black and gold, with a Gotham skyline and a subtle bat-signal in the hero).

## Run locally

```bash
npm install
npm run dev
```

## Edit content

All text — profile, experience, projects, skills, education and contact details — lives in [`src/data.js`](src/data.js).

## Deploy

Every push to `main` deploys automatically to Vercel (the build settings live in [`vercel.json`](vercel.json)). To deploy by hand instead:

```bash
npx vercel deploy --prod
```
